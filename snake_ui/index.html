Neuron Snake

Snake built from 37,521 logic gates, and every gate is a tiny trained neural network: one sigmoid neuron, two for XOR. Every bit of memory is eight NAND neurons in a loop. Nothing is rounded between gates: the screen shows the neurons' real outputs, live in your browser.

The gates

Each gate type was trained from 100 random starts. AND, OR, NAND, NOR and NOT need one neuron (3 weights). XOR and XNOR cannot be one neuron; two neurons with a skip connection (7 weights) always train. Gates were then held to a static discipline: inputs within 0.05 of 0 or 1 must give an output within 0.05, so no error can grow along a chain or around a loop. That needs a training margin of 4.

The machine

Each cell keeps a countdown of how long the snake stays there; the head writes the length, everything else counts down, eating skips one countdown. Walls are the carry out of the position adder. Food comes from a 16-bit shift register. One clock tick is one game step: 48 gates deep, then the flip-flops latch.

Where it came from

Built and checked by run_minigates.py and run_snake.py; this page runs the exported netlist net16.json with the same trained weights. The per-cell countdown follows the third RAM in stevomitric's Logisim Snake, spread over the board as gates.
