## The network

Two inputs x₁, x₂; two hidden sigmoid neurons; one sigmoid output. σ(z) = 1 / (1 + e^(−z)).

    h₁ = σ(w₁₁·x₁ + w₂₁·x₂ + b₁)
    h₂ = σ(w₁₂·x₁ + w₂₂·x₂ + b₂)
    p  = σ(v₁·h₁ + v₂·h₂ + c)

Loss = average over the 4 inputs of −[y·log p + (1−y)·log(1−p)].

### Backward pass

For a sigmoid output with cross-entropy, the error signal at the output is simply δₒ = (p − y) / 4 (the 4 averages over inputs).

| input | p − y | δₒ | δ₁ = δₒ·v₁·h₁(1−h₁) | δ₂ = δₒ·v₂·h₂(1−h₂) |
|---|---|---|---|---|
| (0, 0) | 0.2913 | 0.0728 | 0.0728·-2.02·0.2378 = -0.03498 | 0.0728·-0.23·0.2470 = -0.00414 |
| (0, 1) | -0.7440 | -0.1860 | -0.1860·-2.02·0.2499 = 0.09390 | -0.1860·-0.23·0.2147 = 0.00919 |
| (1, 0) | -0.8444 | -0.2111 | -0.2111·-2.02·0.1407 = 0.05999 | -0.2111·-0.23·0.0550 = 0.00267 |
| (1, 1) | 0.1432 | 0.0358 | 0.0358·-2.02·0.1042 = -0.00753 | 0.0358·-0.23·0.0327 = -0.00027 |

    ∂L/∂v₁ = Σ δₒ·h₁ = 0.0728·0.3894 + (-0.1860)·0.4925 + (-0.2111)·0.8306 + 0.0358·0.8818 = -0.2070

Read the columns as logic: h₁ is on only for (1, 1), so **h₁ = AND(x₁, x₂)**. h₂ is on only for (0, 0), so **h₂ = NOR(x₁, x₂)**. The output is on only when both hidden neurons are off, so **p = NOR(h₁, h₂)**. Together: XOR = NOR(AND, NOR), "one or the other, but not both and not neither".

Why two hidden neurons are needed: one sigmoid neuron draws one straight line through the input square, and no single line separates (0,1), (1,0) from (0,0), (1,1). The hidden layer bends the space so that, in (h₁, h₂) coordinates, the two XOR-true points sit together near (0, 0) and the output neuron's one line can cut them off. The animations show this happening.

Not every start works: with the same recipe, seeds 2, 6 and 8 get stuck for 20,000 steps with one or two outputs at 0.5 (a local minimum where a hidden neuron saturates and stops learning).
