Neuron CPU

An 8-bit computer with a control unit, an ALU and 32 bytes of memory, all talking over one bus. Every one of its 4,352 logic gates is a trained sigmoid neuron (two for XOR), and every memory bit is eight NAND neurons in a loop. Nothing is rounded: the lights show the neurons' real outputs.
